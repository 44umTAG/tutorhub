<h1> Информационная система автоматизации учёта занятий репетитора «TutorHub».</h1>

<h2> Общие сведения о системе.</h2>
<h4>Система с двумя подсистемами реализуется как два веб‑приложения с данными интерфейсами</h4>
Клиентский интерфейс — для родителей и учеников.
Административный интерфейс — для репетитора и ассистента.
Оба интерфейса обращаются к общей базе данных и единой бизнес‑логике. Разделение прав доступа и функционала обеспечивается на уровне ролей пользователей.

<h3> В системе выделены четыре группы пользователей:</h3>
<p>Ученик — просматривает расписание, домашние задания, отмечает выполнение. 
Родитель — просматривает посещаемость и расписание ребёнка, оплачивает абонементы, скачивает чеки, общается с ассистентом.
Репетитор — проводит занятия, отмечает посещаемость, выдаёт и проверяет домашние задания. Не занимается административной работой.
Ассистент — главный администратор системы: добавляет учеников и родителей, управляет расписанием (создаёт, редактирует, исправляет ошибки), контролирует оплаты и абонементы, общается с родителями, видит детальную статистику по каждому ученику.
</p>
